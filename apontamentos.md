# Os meus apontamentos de Git

## Git
- O Git guarda o histórico dos meus ficheiros.
- Um commit é uma fotografia do projeto.
- O VS Code sincroniza com o GitHub num clique.

## Branches
- Um branch é um universo paralelo do projeto.
- O main é o branch principal.

## Colaboração
- Um fork é uma cópia de um projeto na minha conta.
- Um Pull Request propõe alterações ao main.
